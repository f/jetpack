## Evidence to include

For a typical pull request, provide:

- the command and result for each relevant automated check;
- manual test steps and environment;
- before-and-after screenshots for visible behavior;
- accessibility evidence for interaction changes;
- backward-compatibility and migration notes;
- known gaps or follow-up work.
