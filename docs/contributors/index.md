## The shortest successful path

1. Choose a focused issue or documentation improvement.
2. Read the [contribution guide](../CONTRIBUTING.md).
3. Complete the [quick start](../quick-start.md).
4. Create a branch with the [Git workflow](../git-workflow.md).
5. Make the smallest coherent change.
6. Run the relevant tests and quality checks.
7. Add a changelog entry when required.
8. Open a pull request and respond to review.

If you are building a separate plugin or theme that uses Jetpack, switch to [Build with Jetpack](../developers/index.md).
