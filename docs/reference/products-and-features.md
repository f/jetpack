Jetpack includes a core plugin and individual products and plugins. Availability, packaging, and plan details can change.

## Use the owning source

| Question | Source |
| --- | --- |
| What features are currently available? | [Jetpack feature reference](https://jetpack.com/support/features/) |
| How do I install or configure a product? | [Jetpack Support](https://jetpack.com/support/) |
| Which hooks can a plugin or theme use? | [Jetpack Developer Resources](https://developer.jetpack.com/hooks/) |
| How does the Jetpack plugin REST API work? | [Jetpack REST API](../rest-api.md) |
| How do I change Jetpack source? | [Contributor documentation](../contributors/index.md) |
| What does the agency program currently include? | [Jetpack for Agencies](https://jetpack.com/for-agencies/) |

## Avoid stale product claims

Do not copy plan tables, prices, limits, or feature availability into long-lived code comments, AI prompts, or client documents without a source link and review date. Link to the canonical page and verify it when making a decision.
