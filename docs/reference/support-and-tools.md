| Need | Destination |
| --- | --- |
| Install, configure, or troubleshoot Jetpack | [Jetpack Support](https://jetpack.com/support/) |
| Search actions and filters | [Jetpack hooks](https://developer.jetpack.com/hooks/) |
| Learn Jetpack development | [Jetpack Developer Resources](https://developer.jetpack.com/) |
| Check WordPress APIs | [WordPress Developer Resources](https://developer.wordpress.org/) |
| Report a reproducible Jetpack defect | [Jetpack GitHub issues](https://github.com/Automattic/jetpack/issues) |
| Contribute a patch | [Jetpack contributor path](../contributors/index.md) |
| Test a pre-release build | [Jetpack beta testing](../testing/beta-testing.md) |
| Explore the WordPress.com API | [WordPress.com REST API tools](https://developer.wordpress.com/docs/api/) |

When asking for help, include a minimal reproduction and remove secrets. Product support and public issue trackers serve different purposes: use support for site-specific diagnosis and GitHub for reproducible software defects.
