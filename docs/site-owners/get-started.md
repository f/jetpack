Follow this guide when Jetpack is not installed yet or when you are setting up a new WordPress site.

## Before you start

You need:

- administrator access to the WordPress site;
- a site that meets Jetpack's current hosting requirements;
- a WordPress.com account for features that use the WordPress.com cloud;
- a current backup before changing a production site.

## Install and connect

1. In WordPress, go to **Plugins → Add New**.
2. Search for **Jetpack** and confirm that Automattic is the author.
3. Install and activate the plugin.
4. Follow the connection flow.
5. Return to **Jetpack → My Jetpack** and confirm that the site reports a healthy connection.

Use the canonical [Install Jetpack guide](https://jetpack.com/support/getting-started-with-jetpack/) for the current screens and requirements. Read [Why the WordPress.com connection is important](https://jetpack.com/support/why-the-wordpress-com-connection-is-important-for-jetpack/) before deciding how to connect a managed or client site.

## Choose the next task

- To decide what to enable, continue to [Choose Jetpack products and features](choose-products.md).
- To protect the site, continue to [Secure your site](secure-your-site.md).
- To improve speed, continue to [Improve site performance](improve-performance.md).
- If the connection failed, use [Troubleshoot Jetpack](troubleshoot.md).

## Verify the setup

Confirm all of the following:

- WordPress shows Jetpack as active.
- **My Jetpack** opens without a connection warning.
- The site URL and WordPress.com account are the ones you intended to use.
- The site is not a disposable local or staging copy connected as if it were production.
